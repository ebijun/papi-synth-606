# PAPI-SYNTH 606 統合テスト仕様書

## フェーズ1：ハードウェア単体・電源安全テスト
- **HW-01 (電源ライン短絡検査):** IC未挿入状態で 5V-GND および 3.3V-GND 間の抵抗値を測定し、短絡（0Ω付近）がないこと。
- **HW-02 (重要信号ライン導通確認):** DIN Pin1/2/3 および YM2149 各ピン（データバス・BC1・BDIR・CLOCK）の導通を確認すること。
- **HW-03 (供給電圧確認):** USB給電時、U2 Pin40 が +5.0V (±0.25V)、Pico 3V3 が +3.3V (±0.15V) であること。

## フェーズ2：ファームウェア・単体信号テスト
- **FW-01 (2.000MHzクロック出力):** YM2149 Pin22 に約 2.0MHz の 5V 矩形波が出力されること。
- **FW-02 (NetBSD USB複合デバイス認識):** NetBSD に接続し、`dmesg` で `/dev/rmidi0` (`umidi`) と `/dev/ttyU0` (`ucom`) が同時に認識されること。
- **FW-03 (YM2149単体発音テスト):** `/dev/ttyU0` へレジスタ書き込みパケット（`0xAA`）を送信し、Ch.A から矩形波が出力されること。
- **FW-04 (DIN Sync単体出力テスト):** `midish` から Start/Clock を送信し、DIN Pin1 が +5V、Pin3 から 24 PPQN パルスが出力されること。

## フェーズ3：ソフトウェア・実機統合テスト
- **SYS-01 (midish からの TR-606 同期駆動):** `go` / `halt` コマンドで TR-606 が指定 BPM で正確に追従・停止すること。
- **SYS-02 (MIDIキーボード手弾き演奏):** `mode_kbd` 切り替え時、USB MIDI キーボードの打鍵で YM2149 が 3和音発音すること。
- **SYS-03 (p6fmdrv 自動同期統合演奏):** MML の `Z$90,1` 実行と同時に TR-606 が自動スタートし、FM音源と実機 PSG が合奏すること。
- **SYS-04 (終了時フェイルセーフ確認):** PC6001VX 終了時に YM2149 が自動ミュートされ、TR-606 が停止すること。

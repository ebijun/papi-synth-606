# PAPI-SYNTH 606 ユーザーマニュアル

## 1. 起動と接続手順
1. TR-606 背面の SYNC スイッチを **`INPUT`** に設定し、5ピン全結線 DIN ケーブルで接続します。
2. アナログミキサーに以下の3系統を接続します:
   - Ch.1: Raspberry Pi 音声出力（PC6001VX の FM音源・VOICE）
   - Ch.2: PAPI-SYNTH 606 音声出力（実機 YM2149 の PSG音源）
   - Ch.3: Roland TR-606 モノラル出力
3. NetBSD 上で `./software/scripts/start_synchub.sh` を実行します。
4. PC6001VX の環境設定で **機種: PC-6001mkIISR**、**PSG音量: 0（ミュート）**、**OPN(FM)音量: 100** に設定します。

## 2. はっしー氏FM音源ドライバ（p6fmdrv）データの再生
### A. 既存データ（.d88 / .p6）を無改造で鳴らす場合
1. PC6001VX 上でドライバと曲データをロードして再生を開始します（FMはPiから、PSGは実機YM2149から発音）。
2. `midish` コンソールで曲のテンポ（例: `t 128`）を入力し、小節の頭に合わせて `go` を実行すると TR-606 が走り出します。

### B. MML にトリガーを埋め込んで TR-606 と完全自動同期させる場合
MML の演奏開始位置に `Z$90,1`、終了位置に `Z$90,0` を記述してコンパイルします。
```text
#TEMPO 128
A @1 o4 l8 Z\$90,1 cdef gab>c <bagf edc4 Z\$90,0
```
`midish` でテンポだけ `t 128` と合わせておけば、PC6001VX の演奏開始と同時に TR-606 が自動スタートします。

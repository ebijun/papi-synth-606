# P6-YM2149-606 SYNC HUB 基板実装ガイド

## 1. 基板仕様
- 外形寸法: 95mm x 75mm (2層基板 / 表面シルク: P6-YM2149-606 SYNC HUB)
- 固定穴: 四隅 M3用 (φ3.2mm)
- 外部端子: 基板直付けフットプリント ＋ 2.54mmピッチ引き出しランド並列配置

## 2. 実装部品リスト (BOM)

| 記号 | 部品名 | 仕様・定数 | 数量 | 備考 |
| :--- | :--- | :--- | :---: | :--- |
| U1 | Raspberry Pi Pico | 20pin×2 ピンソケット実装 | 1 | USB複合デバイス |
| U2 | YAMAHA YM2149 | DIP-40 ICソケット実装 | 1 | 5V駆動 PSG音源 |
| U3-U5 | ロジックレベル変換 | BSS138 4ch双方向モジュール | 3 | 3.3V⇔5V変換 |
| J1 | 5ピン DIN メスコネクタ | 基板直付け または 外付けJ1_EXT | 1 | TR-606 DIN Sync出力 |
| J2 | 3.5mm オーディオジャック | モノラル/ステレオ (J2_EXT併用可) | 1 | YM2149 音声出力 |
| R1, R2 | 保護抵抗 | 220Ω (1/4W カーボン) | 2 | DIN Sync 出力保護 |
| R3-R5 | ミックス抵抗 | 1kΩ (1/4W カーボン) | 3 | Ch.A, B, C 合成用 |
| R6 | 出力プルダウン抵抗 | 10kΩ〜47kΩ (1/4W) | 1 | ポップノイズ防止 |

## 3. 組み立て順序と注意点
1. 背の低い部品（抵抗 R1〜R6 → 積層セラミックコンデンサ C2, C3）からはんだ付けします。
2. ICソケット（DIP-40）とモジュール用ピンソケット（U1, U3〜U5）を取り付けます。
3. 電解コンデンサ C1 は**極性（＋／－）**に注意し、＋側（長い足）を YM2149 側に向けて実装します。
4. すべての IC・モジュールを挿す前に、USB給電して **5V ラインと 3.3V ラインの電圧** をテスターで確認してください。
